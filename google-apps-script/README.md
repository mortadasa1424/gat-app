# GAT lead-capture Apps Script

This is not part of the deployable frontend (`GAT app/`) — it's the source for
the Google Apps Script Web App the lead form POSTs to. It lives here because
this repo has no way to edit the live Apps Script project directly; paste
`Code.gs` into the Apps Script editor yourself.

See the comment block at the top of `Code.gs` for the diagnosis and the exact
setup steps (spreadsheet ID, paste, **redeploy a new version**, then check
Executions).
